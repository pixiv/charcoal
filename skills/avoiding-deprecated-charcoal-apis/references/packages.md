# `@charcoal-ui/*` packages: role and status

All twelve packages are published and versioned together. Status matters more than role: three of them look usable but should not enter new code.

## Current

| Package                        | Role                                                                                                                                                    | Import directly in new code?                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `@charcoal-ui/react`           | React components (Button, Modal, Pagination, Switch, Icon, Carousel…). Plain CSS via `dist/index.css` / `dist/layered.css`; no styled-components needed | Yes — the default place to look for a component                                             |
| `@charcoal-ui/theme`           | Theme types, `light` / `dark` objects, token CSS (`css/v1/remap.css`, `css/v2/light.css`, `css/v2/dark.css`), `token-object`, `tokens/*`                | Yes — mostly for its CSS files and types                                                    |
| `@charcoal-ui/tailwind-config` | Tailwind preset / `createTailwindConfig`. New Design Token 2.0 utilities land here first                                                                | Yes, in `tailwind.config.*`                                                                 |
| `@charcoal-ui/icons`           | `<pixiv-icon>` custom element; `css/*`, `react/v1`, `react/v2` subpaths                                                                                 | Yes for plain HTML / SSR. In React, prefer `Icon` from `@charcoal-ui/react`, which wraps it |
| `@charcoal-ui/icon-files`      | Icon SVGs as strings (root = v1 set, `/v2`, `/v1/datauri`, `/v2/datauri`). Generated by `icons-cli`                                                     | Rarely — only when you need raw SVG strings                                                 |
| `@charcoal-ui/foundation`      | Primitive types and values (spacing, typography, grid, colors, effects)                                                                                 | Rarely — usually reached through `theme`                                                    |
| `@charcoal-ui/utils`           | Helpers (color mixing, CSS). The README says it is mainly for internal use                                                                              | No                                                                                          |

## Deprecated or frozen — do not add to new code

| Package                      | Status                                                                                              | Use instead                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `@charcoal-ui/react-sandbox` | Deprecated since v6; removal considered for the next major [2]. Its README still only says "試験的" | `@charcoal-ui/react` — see the mapping list in SKILL.md                |
| `@charcoal-ui/styled`        | Frozen at Design Token 1.0; no new features. Not formally deprecated except `createTheme` [3]       | `@charcoal-ui/react` + CSS variables or `@charcoal-ui/tailwind-config` |
| `@charcoal-ui/tailwind-diff` | Scheduled for discontinuation (廃止予定) [1]                                                        | Nothing provided                                                       |
