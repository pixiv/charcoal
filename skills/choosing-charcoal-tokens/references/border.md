# ボーダーガイドライン

Charcoal のボーダーの使い方と、太さのトークンを選ぶときの指示。トークン名を使う。色はボーダー色のトークンに従い、この文書では色を再定義しない。

見本は用途の確認用である。見本に現れる部品へ、見本だけを理由にボーダーを割り当てない。使用例の指定がないトークンへ、見本を理由に用途を足さない。

## 概要

ボーダーは、要素間の視覚的な区切りや、階層構造を示す要素である。

ボーダーを使う前に、余白や異なる背景色で足りないかを検討する。ボーダーを過剰に使うと、画面が煩雑になる。

## 使い方

### コンテナを背景と区別する

コンテナ色と背景色が同じとき、コンテナにボーダーを付けると要素を区別しやすい。Charcoal では影（Drop Shadow）はあまり使わず、ボーダーを使う。

見本は、Menu 全体へのボーダーと、お知らせへのボーダーである。

### グルーピングを示す

ボーダーを使うと、見出しなしで項目をグループにできる。

見本は Menu の内部に Line を入れ、見出しなしでグループを示す場合である。

### リスト内の項目を区別する

次の場合は、余白よりボーダーが適する。

- 同時に多くの内容を表示したいとき。
- 要素が細長く、中央にも余白があるとき。

### 要素をハイライトする

強調はボーダーで表せる。見本は Focus 状態と Error 状態である。

### 使わないケース

小さい、かつ操作できる要素には、コンテナ色による区別を優先する。Button や Text Field が該当する。

- する: コンテナ色で背景と区別する。
- しない: ボーダーで区別する。

## 太さ

| トークン | 値 | 使うとき |
| --- | --- | --- |
| `border-width.m` | 1px | 基本の太さ。使用例の指定はない。 |
| `border-width.l` | 2px | 高いコントラスト比が必要なとき、または強調が必要なとき。使用例の指定はない。 |
| `border-width.focus.1` | 1px（`border-width.m` を参照） | フォーカスインジケータの内側の枠線。インジケータのコントラスト比を上げる。見本は Button。 |
| `border-width.focus.2` | 2px（`border-width.m` を参照） | フォーカスインジケータの外側の枠線。インジケータの面積を広げつつ、`border-width.focus.1` と組み合わせ、任意の背景でもコントラスト比を保証する。見本は Button。 |

フォーカスインジケータは `border-width.focus.1` と `border-width.focus.2` を組にして使う。

## 色

ボーダーの色は、ボーダー色のトークンに従う。

OS ネイティブのコンポーネントを使うときは、OS のスタイルやデザインシステムに従う。
