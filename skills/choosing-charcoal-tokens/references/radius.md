# 角丸ガイドライン

Charcoal の角丸の使い方と、角丸トークンを選ぶときの指示。トークン名を使う。

見本は用途の確認用である。見本に現れる部品や px へ、見本だけを理由にトークンを割り当てない。用途が「保留」のトークン、および使用例の指定がないトークンへ、用途を推測で足さない。

## 概要

角丸は、柔らかい雰囲気を示しながら、UI 要素の分類を示唆するスタイルである。Charcoal ではほとんどの要素に使う。

## 使い方

角丸は次の 3 つに従って選ぶ。

### 関連する要素には同じ値を使う

同時に使われやすい要素、または関連性が高い要素には、同じ角丸を使うのが理想である。フォーム内の入力用コンポーネントは、高さと角丸を揃えるとわかりやすい。同種のコンポーネントは、大きさや密度が異なっていても、なるべく同じ丸みを維持する。

見本では、入力用コンポーネントに同じ 4px の角丸を使っている。

### 要素の大きさに合わせて丸みを調整する

大きい要素には大きい丸み、小さい要素には小さい丸みを使い、全体のバランスを取る。コンテナに含まれる要素は、親コンテナより小さい丸みにするとよい。

見本は、外側が 16px、その中が 8px、さらに中が 4px の角丸である。

### 円形で視線を引く

円は視線を引きやすく、画面の流れをコントロールし、重要な要素を強調できる。円形は、ボタンなど、フロー上で重要な要素にだけ使う。

3 つの原則を同時に適用した見本は次のとおり。

- 入力項目は 4px。
- サムネイルは 8px。
- 背面にあるパネルは 16px。
- 前面に浮かぶ Modal は 24px。
- Primary Button は 999999px。

## トークン

値は、括弧内のスペーストークンを参照する。`radius.oval` に参照先の指定はない。

| トークン | 値 | 使うとき |
| --- | --- | --- |
| `radius.0` | 0px（`space.0` を参照） | 角丸を使わないことを明示するとき。コンテンツ画像の全貌、レイアウト用要素など。使用例の指定はない。 |
| `radius.xs` | 2px（`space.1` を参照） | 保留。用途を推測で割り当てない。 |
| `radius.s` | 4px（`space.10` を参照） | 入力項目、バッジなど。見本は NEW。 |
| `radius.m` | 8px（`space.20` を参照） | サムネイル、メニューなど。使用例の指定はない。 |
| `radius.l` | 12px（`space.25` を参照） | 保留。用途を推測で割り当てない。 |
| `radius.xl` | 16px（`space.30` を参照） | パネル、チュートリアルツールチップなど。見本は Tool Tip。 |
| `radius.xxl` | 24px（`space.40` を参照） | モーダルなど、前面に出したいもの。使用例の指定はない。 |
| `radius.oval` | 999999px | ボタンなど、注意を引きたい要素。見本は Button。 |

## 例外

OS ネイティブのコンポーネントを使うときは、OS のスタイルやデザインシステムに従う。

フォーカスインジケータは、コンポーネントより 1〜2px ほど大きくする必要がある。そのため、例外的な値が必要になる場合がある。そのような特別な場合は、コンポーネントトークンの利用を推奨する。例は `radius.checkbox.focus` である。この名前は例であり、コンポーネントトークンの全一覧ではない。
