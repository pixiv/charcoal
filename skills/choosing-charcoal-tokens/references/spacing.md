# スペーシングガイドライン

Charcoal のスペーストークン、レイアウトトークン、ターゲットサイズを選ぶときの指示。トークン名を使う。

見本は用途の確認用である。表の「使うとき」が名指ししていない部品へ、見本だけを理由に割り当てない。用途の指定がないトークンへ、近い値の用途を割り当てない。

## スペーストークン

余白や空間に使うアプライドトークンをスペーストークンと呼ぶ。要素間の関係を作るために広く使う。

値の数字は共通である。単位はプラットフォームで変わる。iOS は pt、Android は dp、Web は px である。

使う場所は次のとおり。

- テキストやコンポーネントなど、要素と要素のあいだ。
- ハイレベルなコンテナのパディング。セクション、記事、パネルはハイレベルなコンテナである。
- 画面レベルのグリッドには、レイアウト用トークンを使う。

### コンポーネントの内部

シンプルなコンポーネントの内部にスペーストークンを使う必要はない。Button のように、コンポーネント全体が一つの要素である場合は、要素間の関係を作る状況ではない。

複数の要素を内包するコンポーネントは、ハイレベルなコンテナとみなし、スペーストークンを使う。Modal もこの場合にあたる。

## レイアウト

関係性の強さに対応するトークンである。迷ったときは `layout.30` から試す。


| トークン         | 値   | 使うとき                                                        |
| ------------ | --- | ----------------------------------------------------------- |
| `layout.0`   | 0   | 余白なしを明示する。                                                  |
| `layout.10`  | 4   | 最小限のスペーシング。                                                 |
| `layout.20`  | 8   | 関係性が非常に高く、セットとして見なす要素のあいだ。Text Field の要素間など。                |
| `layout.25`  | 12  | 用途の指定はない。                                                   |
| `layout.30`  | 16  | 関係性の高い要素。Default 密度の Body の文字サイズと同じ。                        |
| `layout.40`  | 24  | 関係性が少しある要素のあいだ。少し違うグループと見なされる。リスト内のアイテム間、中サイズのコンテナのパディングなど。 |
| `layout.50`  | 40  | 関係性が弱い要素のあいだ。                                               |
| `layout.60`  | 64  | 関係性がほぼない要素のあいだ。セクション、パネルなど。                                 |
| `layout.70`  | 104 | 用途の指定はない。                                                   |
| `layout.80`  | 168 | 用途の指定はない。                                                   |
| `layout.90`  | 272 | 用途の指定はない。                                                   |
| `layout.100` | 440 | 用途の指定はない。                                                   |




## ターゲットサイズ

タップやクリックできる領域の大きさをターゲットサイズと呼ぶ。小さすぎると誤タップの原因になり、操作性が下がる。情報密度が高い場合でも、最低限のターゲットサイズを保証する。

トークンは意思決定の目安である。色のコントラスト比と同様に、常に高い水準を目指す。Default 密度で 56px を確保できるなら、その方が望ましい。

使い方は、最小の高さをターゲットサイズにすることである。コンポーネントの外側の余白や、コンポーネント間の間隔をタップ領域に含めてよい。それにより、ターゲットサイズを保ったまま情報密度を上げられる。見本は、外側の余白をターゲットサイズに含めた Checkbox である。


| トークン        | 値    | 使うとき                                                        |
| ----------- | ---- | ----------------------------------------------------------- |
| `target.xs` | 24px | 最低限のターゲットサイズ。WCAG Level AA の要求値。                            |
| `target.s`  | 32px | Compact 密度の推奨値。S サイズの Button など。                            |
| `target.m`  | 40px | Default 密度の推奨値。M サイズの Button、Text Field など。                 |
| `target.l`  | 48px | Cozy 密度での最低限の値。WCAG Level AAA、Apple の推奨値、Android の推奨値を満たせる。 |
